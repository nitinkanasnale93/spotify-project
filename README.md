Spotify-Inspired Music Player
A browser-based music player built with HTML, CSS, and vanilla JavaScript. This project recreates a simple music-streaming interface for learning and practicing frontend development.
Live Demo
Open the Music Player
Features
- Play and pause audio
- Select a song from the playlist
- Skip to the next or previous song
- Seek through a song using the progress bar
- Display song titles and album artwork
- Show a playback animation while music is playing
Built With
- HTML5
- CSS3
- JavaScript
- Browser Audio API
- Git and GitHub
- Render (static-site hosting)
Run Locally
1. Clone the repository:
   git clone https://github.com/nitinkanasnale93/spotify-project.git
2. Open the project folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension in VS Code.
4. Keep the audio files and images in the project folder so their relative paths resolve correctly.
What I Practiced
- Selecting and updating DOM elements
- Handling click and input events
- Managing audio playback with JavaScript
- Updating the progress bar from the current playback time
- Seeking through audio using the media element's currentTime and duration
- Deploying a static frontend project
