## ✨ About the Project

This project recreates a simple music-listening experience directly in the browser. It uses vanilla JavaScript and the browser's built-in Audio API to manage playback and update the interface as songs play.

The project was built to strengthen my understanding of JavaScript fundamentals, DOM manipulation, event handling and browser audio playback.

## 🚀 Features

| Feature | Description |
|---|---|
| ▶️ Play & Pause | Control music playback |
| 🎶 Song Playlist | Select a track from the available songs |
| ⏭️ Next & Previous | Navigate between tracks |
| 🎚️ Seekable Progress Bar | Click or drag to jump to a specific position in a song |
| 🖼️ Album Artwork | Display artwork alongside the playlist |
| 🎧 Playback Indicators | Update the player interface during playback |

## 🛠️ Tech Stack

- **HTML5** — structures the music player.
- **CSS3** — handles layout, styling and visual presentation.
- **JavaScript** — implements playlist interactions and playback controls.
- **HTML Audio API** — plays audio and supports seeking.
- **Font Awesome** — provides player-control icons.
- **Git & GitHub** — version control and source-code hosting.
- **Render** — hosting and deployment of the static website.

## 💻 Run Locally

Want to run the project on your own computer?

**1. Clone the repository**

```bash
git clone https://github.com/nitinkanasnale93/spotify-project.git
```

**2. Open the project folder**

```bash
cd spotify-project
```

**3. Launch the website**

Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.

No package installation or build command is required.

Keep the HTML, CSS, JavaScript, audio and image files in their expected locations so the player can load its assets correctly.
